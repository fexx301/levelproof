# LevelProof two-minute demonstration

This script uses only the product’s real workflow. If a model response is not
available, label the seeded scene/ghost playback as a deterministic backup; do
not present it as live generation.

## Primary run

1. Open **The Balcony Vault**. Point out the empty vault and the prompt field.
2. Click **Key + locked door** under **Try**. Wait for **Edit preview**.
3. Say: “The proposal is staged. Nothing has changed yet.” Show the red/green
   markers and the explicit approval button.
4. Click **Apply edit**, then **Play the level**. The accepted checkpoint is now
   the edited level.
5. Click **The switch trap**. Apply the proposed trap even if it leaves a
   draft. The checks should show Recovery failed while the solution remains
   reachable.
6. Click **Show the problem** under Recovery. The app opens the verifier’s
   witness replay, highlights the implicated ids, and explains the stranded
   state using engine facts.
7. Return to editing, click **Find repairs**, preview the switch relocation,
   and click **Apply**.
8. Click **Replay the failing route**. The old witness is replayed only after
   it has been validated against the repaired level.
9. Click **Save accepted checkpoint**, then **Share**. State clearly that the
   shared link contains the accepted scene, not an unapproved draft.

## Backup demonstration

Use the seeded gallery scenes and their verifier ghost replays to show that the
checker is deterministic. Label this as a seeded/deterministic demonstration;
it does not prove live model behavior.

## Claims to avoid

- Do not call a fixture result a live AI result.
- Do not claim accounts, cloud saves, multiplayer, or arbitrary mesh modeling.
- Do not claim Safari or real-device support without running those devices.
- Do not claim that a single winning route proves recovery.
